# 🎨 Art Gallery Management System

## 📌 About the Project

The **Art Gallery Management System** is a software application designed to simplify and automate the management of an art gallery. It helps administrators efficiently manage artists, artworks, exhibitions, customers, and sales.

The system reduces manual paperwork, improves data organization, and provides an easy way to maintain and access gallery information.

## ✨ Features

* 👨‍🎨 Manage artist information
* 🖼️ Add, update, and delete artwork details
* 🏛️ Manage art exhibitions
* 👥 Manage customer information
* 💰 Track artwork sales and purchases
* 🔍 Search and view artworks
* 📊 Maintain organized gallery records
* 🔐 User/admin management
* 🗃️ Database-based information storage

## 🛠️ Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Python / PHP / Java

## 🚀 How It Works

1. The administrator logs into the system.
2. Artist and artwork details are added to the database.
3. Artworks can be categorized and displayed.
4. Exhibitions can be created and managed.
5. Customer information and purchases are recorded.
6. Administrators can update or remove records whenever required.
